# שלב ה' - דוח פרויקט: ממשק משתמש גרפי (GUI) למערכת RideFlow

ממשק גרפי זה נבנה כרשת ניהול נסיעות מתקדמת ודינמית המאפשרת שליטה מלאה על מסד הנתונים `merged` (בסיס נתונים מסוג PostgreSQL). המערכת תוכננה מן היסוד על מנת לספק חוויית משתמש חלקה, מהירה ומודרנית תוך התמודדות יעילה עם עשרות אלפי רשומות הקיימות במסד הנתונים.

הממשק מעוצב בקו נקי ותומך במצב כהה (Dark Slate Theme) מלא עם התאמה מושלמת לעברית (RTL).

## 🛠️ הסבר על דרך העבודה והכלים

המערכת נבנתה בארכיטקטורת **Client-Server (REST API)** מונעת אירועים, המפרידה בצורה מלאה בין לוגיקת השרת לתצוגת הלקוח.

### 1. שרת ה-Backend (פייתון)
ממוקם בקובץ [app.py](file:///c:/Users/Home/rideFlowProject/ex5/app.py):
- **Flask**: משמש כשרת אינטרנט קל המנגיש את דפי ה-Frontend (קבצים סטטיים) ומספק נקודות קצה (API Endpoints) בפורמט JSON עבור כל פעולות ה-CRUD, השאילתות והפרוצדורות.
- **Psycopg2**: ספריית הקישוריות הרשמית לחיבור וביצוע פקודות ישירות מול מסד הנתונים PostgreSQL.
- **ניהול תהליכים ועסקאות (Transactions)**: כל בקשה לשרת מתבצעת תחת ניהול עסקאות תקין עם ביצוע `commit` במקרה של הצלחה ו-`rollback` במקרה של שגיאה, למניעת עיוות נתונים.
- **לוגים וניטור DB Notice**: השרת מאזין להודעות `RAISE NOTICE` הנשלחות מתוך הפרוצדורות ב-PostgreSQL ומחזיר אותן לקליינט כדי להציג למשתמש לוג ריצה מפורט.

### 2. ממשק המשתמש (Frontend)
ממוקם תחת התיקייה [static](file:///c:/Users/Home/rideFlowProject/ex5/static):
- **HTML5 סמנטי** ([index.html](file:///c:/Users/Home/rideFlowProject/ex5/static/index.html)): מבנה דף נקי, סמנטי ונגיש.
- **CSS3 מותאם אישית** ([style.css](file:///c:/Users/Home/rideFlowProject/ex5/static/css/style.css)): עיצוב מודרני מבוסס Slate Dark Theme, שימוש במשתני CSS (Custom Properties), אפקטים שקופים (Glassmorphism), אנימציות מעבר עדינות (transitions) ועיצוב מגיב (Responsive Grid & Flexbox).
- **JavaScript (Vanilla - ES6)** ([main.js](file:///c:/Users/Home/rideFlowProject/ex5/static/js/main.js)): ניהול דינמי לחלוטין של הממשק במודל **SPA (Single Page Application)** - מעבר בין מסכים, פתיחת דיאלוגים (Modals) וביצוע בקשות אסינכרוניות (`fetch` AJAX) מול השרת ללא צורך בריענון הדף.

### ⚡ אופטימיזציות מיוחדות לעבודה עם עשרות אלפי נתונים
כדי למנוע קריסה או קפיאה של הדפדפן עקב כמות הנתונים העצומה במסד הנתונים, הוטמעו הפתרונות הבאים:
1. **טעינה עצלה של אפשרויות (Lazy Options Loading)**: בניגוד לגרסאות קודמות שטענו את כל אפשרויות הבחירה (Dropdowns) של הנהגים, הנוסעים והנסיעות מיד בטעינת הדף (דבר שגרם לקפיאת הדפדפן), כעת הנתונים נטענים פעם אחת בלבד ורק בעת כניסה למסך הרלוונטי או פתיחת חלון הוספה/עריכה.
2. **הגבלת תוצאות ודפדוף (Query Limits)**: בשרת [app.py](file:///c:/Users/Home/rideFlowProject/ex5/app.py) הוגדר LIMIT דינמי לשאילתות (ברירת מחדל של 100 רשומות, מקסימום 500) המונע שליפה של עשרות אלפי שורות בבת אחת לדפדפן.
3. **סינון בצד הלקוח מבוסס Cache (Fast Client-Side Filtering)**: מנגנון החיפוש הדינמי בטבלאות אינו פונה לשרת בכל הקלדה ואינו סורק את ה-DOM (דבר שיוצר האטה משמעותית). במקום זאת, הוא יוצר Cache טקסטואלי מראש ומסנן שורות בזיכרון באופן מיידי.
4. **פתרון מפתחות זרים ידידותי**: המערכת מבצעת שאילתות `JOIN` מובנות בשרת כדי להציג שמות ברורים (כמו שם הנהג, שם הנוסע, מזהה נסיעה מפורט ושמות תחנות מילוליים) במקום להציג מזהים מספריים חסרי משמעות.

### 7. פונקציות ופרוצדורות (שלב ד')
במסך זה המשתמש יכול להפעיל את תתי-התוכניות שנכתבו ב-PL/pgSQL בשלב ד' של הפרויקט:

#### א. הרצת פרוצדורות (Procedures)
- **ביטול נסיעה ועדכון הרשמות (`cancel_trip_and_notify`)**: מבצע ביטול נסיעה ומעדכן את כל הנוסעים הרשומים אליה לסטטוס 'Cancelled' באמצעות Cursor. בתמונה ניתן לראות את הודעות ה-`NOTICE` המפורטות המוחזרות ישירות ממסד הנתונים.
- **הרשמת נוסע לנסיעה עם עדכון מקומות (`register_passenger_to_trip`)**: רושם נוסע לנסיעה ומפחית אוטומטית את כמות המושבים הפנויים בנסיעה ב-1.
![הרצת פרוצדורות](screenshots/Screenshot%202026-06-21%20200032.png)

#### ב. הרצת פונקציות (Functions)
- **שליפת נסיעות פעילות של נוסע (`get_passenger_active_trips`)**: מחזירה Ref Cursor המכיל את כל הנסיעות והסטטוסים של הנוסע, והממשק הגרפי מציג אותן בטבלה.
- **חישוב מקומות פנויים במסלול (`get_route_available_seats`)**: מחשבת באמצעות Explicit Cursor סורק ולולאה את כמות המושבים הפנויים הכוללת במסלול מסוים ומציגה את המספר למשתמש.
![הרצת פונקציות](screenshots/Screenshot%202026-06-21%20195746.png)
