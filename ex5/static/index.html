ברוכים הבאים ל-RideFlow Management System

כאן תוכלו לנהל את כל היבטי רשת הנסיעות המשותפות שלכם. המערכת מאפשרת ניהול מלא של טבלאות המפתח, הרצת שאילתות סטטיסטיות מתקדמות, וביצוע תהליכים אוטומטיים באמצעות פונקציות ופרוצדורות הרצות בתוך מסד הנתונים.

טוען נתונים...

📊 שאילתא 1: נסיעות מעל הממוצע

מציגה את הנסיעות שבהן כמות ההרשמות גבוהה מהממוצע הכללי של הרשמות לנסיעה במערכת.

👨‍✈️ שאילתא 2: נהגים פעילים במיוחד

מציגה נהגים אשר רשומים ומשויכים ליותר מ-3 נסיעות שונות במערכת.

🗺️ שאילתא 3: כמות הרשמות לכל מסלול

מציגה את רשימת המסלולים ממוינת לפי סך כל ההרשמות שהתבצעו לנסיעות בהם בסדר יורד.

תוצאות שאילתה

❌ ביטול נסיעה ועדכון הרשמות (Procedure)

מפעיל את הפרוצדורה `cancel_trip_and_notify` המעדכנת את סטטוס הנסיעה ל-'Cancelled', ובאמצעות Cursor מעדכנת את כל ההרשמות התואמות ל-'Cancelled'.

📝 הרשמת נוסע לנסיעה עם עדכון מקומות (Procedure)

מפעיל את הפרוצדורה `register_passenger_to_trip`. מבצע הרשמה (DML), מוריד מקום פנוי מהנסיעה (DML), ובודק שקיים מקום פנוי ושהנוסע קיים.

🔍 שליפת נסיעות פעילות של נוסע (Function - Ref Cursor)

קורא לפונקציה `get_passenger_active_trips` המחזירה Ref Cursor המכיל את כל הנסיעות והסטטוסים של הנוסע.

מזהה הרשמה סטטוס הרשמה מזהה נסיעה תאריך שעת יציאה סטטוס נסיעה שם מסלול

💺 סך מקומות פנויים במסלול (Function - Loops & Cursor)

קורא לפונקציה `get_route_available_seats` המחשבת באמצעות Explicit Cursor ולולאה את סך המקומות הפנויים בכל הנסיעות המשויכות למסלול זה.
